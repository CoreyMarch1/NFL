A preliminary power-rating engine for Week 2

Built on the composite of six public models (FPI, nfelo, Inpredictable, Unexpected Points, FTN DVOA, PFF), decomposed into offense/defense splits and run through a 5,000-iteration Monte Carlo per game. Treat this as a v0 baseline — see improvement levers for what would materially sharpen it before staking real money on it.

02  /  FEATURES

With only one confirmed Week 2 result on the board, a true accuracy-driven feature-importance regression isn't supportable yet (see lever #1). What is computable from the published table today: how tightly each source tracks the six-model consensus, and how far it typically strays from it.

Correlation to composite

Pearson r across all 32 teams — higher means that model moves in lockstep with the consensus (less independent signal, but more "central").

Mean absolute deviation from composite

Week 2 matchup projections

03  /  SIMULATION

Each of the 16 games: 5,000 Monte Carlo draws on margin (Normal, mean = rating differential + 2.0-pt home-field, sd blended from a 13.0-pt base game-variance and each team's model-disagreement) and total points (Normal on combined offensive ratings). Where a market line was available, it's shown alongside for reference.

Reality check: Thursday's game

04  /  VALIDATION

The Week 2 slate opened Thursday night, so one result is already in — a live, if tiny, sanity check on the engine before the other 15 kick off.

Buffalo Bills 41 – Detroit Lions 31

Final, Thu Sept 17 · Highmark Stadium

BUF +10

Actual margin. Model's expected margin was BUF +4.7 (median sim +4.4), with a 68% interval of [−8.6, +17.7] and a 95% interval of [−21.7, +29.6].

✓ Actual result fell inside the 68% CI

Reading this correctly

One game is not a validation set — it's one draw from a distribution that's 13–15 points wide by design. The market (BUF −5.5) was closer to the eventual margin than the model's +4.7, which is the expected pattern this early: Vegas prices injuries, weather, and sharp money the composite doesn't see. That gap is exactly what lever #2 below is for.

Score-wise, the model projected BUF 26.7–DET 22.3 (total 49.0) against an actual 41–31 (total 72) — both teams well over the model's total, which the off/def split (built on a 22.5-pt league-average baseline, not this specific matchup's pace) had no way to anticipate.
